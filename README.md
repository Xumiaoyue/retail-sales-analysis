# 小売売上データ分析

公開されている架空の小売注文明細1,000件をMySQLに取り込み、2023年1月から2024年12月までの売上を分析しました。SQLで月別・商品カテゴリ別に集計し、Excelで集計表と月別売上高の折れ線グラフを作成しました。

## 主な分析結果

- 月別売上高が最も高かったのは2023年2月で、69,236.92でした。
- 商品カテゴリ別では、Technologyの売上高が639,512.88、利益額が142,759.37で、いずれも3カテゴリの中で最も高くなりました。

## ファイル

- `小売売上分析レポート.xlsx` — 集計表と月別売上高のグラフ
- `category_sales.sql` — 商品カテゴリ別の売上高・利益額の集計
- `monthly_sales.sql` — 月別売上高の集計
